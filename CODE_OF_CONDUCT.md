# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful. Harassment, personal attacks, and demeaning comments are not tolerated.

Report unacceptable behaviour by opening a [private security advisory](https://github.com/PyModel/claude-agy-mcp/security/advisories/new) or contacting [@elkaix](https://github.com/elkaix). Maintainers may warn, remove content, or ban participants.
